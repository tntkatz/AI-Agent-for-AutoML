# AI-Agent for AutoML

Автономный AI-агент, решающий задачи машинного обучения под ключ (от анализа описания до генерации итогового предсказания).

## Ограничения среды запуска
* Python 3.12, 8 CPU, 32 GB RAM.
* Лимит выполнения: до 3 часов на задачу.
* Доступ в интернет из контейнера закрыт.
* Единая точка входа — `solution.py` в корне проекта.
